# Contributing

Help us build a tiny, auditable credential handoff tool. We welcome issues, documentation corrections, security reviews, compatibility tests, and new adapter ideas.

Read the repository [contribution guide](https://github.com/Yolgie/kuriergepaeck/blob/main/CONTRIBUTING.md) before opening a pull request. For vulnerabilities, follow [private disclosure instructions](https://github.com/Yolgie/kuriergepaeck/blob/main/SECURITY.md); do not post secrets in public issues.
