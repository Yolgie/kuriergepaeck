# Kuriergepäck

A privacy-focused, open-source credential handoff project.

**Status: early development — not ready for real credentials.**

Kuriergepäck is designed to transfer a single, explicitly approved credential from a trusted source device (initially KeePass2Android on Android) to a browser over an end-to-end encrypted channel through a minimal self-hosted relay. The relay never receives the KeePass vault or plaintext credential.

The project intends to support other password managers and source devices over time. No released implementation or security audit is available yet.

See upcoming architecture, threat-model and contributor documentation.
